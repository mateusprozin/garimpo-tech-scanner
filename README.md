## Como usar

1. No site do Garimpo Tech, abra **Meus computadores** e clique em **Cadastrar automaticamente**.
2. Baixe, execute e conclua a instalacao. O aplicativo nao exige .NET instalado.
3. O Scanner se conecta sozinho a sessao criada pelo site. Se necessario, cole o link `garimpotechscanner://...` em **JA TENHO O LINK DE CONEXAO**.
4. Autorize a analise, confira os componentes detectados e confirme o envio.
5. Revise os campos preenchidos no site e clique em **Salvar computador**.

O Scanner so le o hardware depois da sua autorizacao e so envia os dados depois de uma confirmacao separada. Nenhuma chave secreta do Supabase esta embutida no executavel.
